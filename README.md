# FinansApp BTC & Krypto Scanner ⚡

En moderne Next.js applikasjon dedikert til **Bitcoin** og alle ledende **kryptovalutaer**, med sanntidsdata og kryptolister hentet direkte fra Yahoo Finance sin kryptoseksjon.

## Nøkkelfunksjoner
- **100% Krypto-fokus**: Alle tradisjonelle aksjer er fjernet. Konsentrert utelukkende om Bitcoin (BTC) og kryptovalutaer.
- **Yahoo Finance Krypto-screener**: Automatisk henting og visning av kryptovalutaer med kurs, 24t endring %, markedsverdi og volum.
- **Trading Hints & Signaler**: Tekniske indikatorer (RSI, 7-dagers glidende gjennomsnitt SMA7, og volum) som genererer anbefalings-hints (`🟢 KJØP`, `🔴 SELG`, `🟡 OBSERVER`).
- **Interaktiv Graf**: Chart.js kursgraf for Bitcoin og alle andre kryptomynter med tidsintervaller (24 timer, 7 dager, 1 måned, 6 måneder, 1 år).
- **Favorittliste**: Legg til og overvåk egne kryptovalutapar.

## Kom i gang

Kjør utviklingsserveren:

```bash
npm run dev
```

Åpne [http://localhost:3000](http://localhost:3000) i nettleseren din.
